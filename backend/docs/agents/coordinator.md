## IMA 模块边界与验收

- 输入查询、图片需求及已确认型号；输出未入库证据、候选或明确错误。Backend 分配业务 ID 并保存。
- 不在 IMA 模块写 HTTP、数据库或营销文案；凭证只由服务端运行时使用。
- media_id 来自线上 API；来源不能是本地路径；未知型号不得混用。
- 说明图片是否需要后端代理/刷新；Backend 实现访问接口，Frontend 实际显示并检查。
- 验证只报告配置状态，不输出凭证；交接附实际运行命令与未解决的外部权限问题。
