## 安全同步与回执

先检查状态及未提交路径；仅合并职责提交，不 reset/clean，不覆盖/代提交在途业务代码。
分叉分支普通合并；可快进分支快进；未提交文件与基线重叠或出现冲突时停止该分支同步，明确报告。
同步后验证基线为祖先、原业务提交仍可达、代码没有被职责变更改写，IMA 未提交内容仍在。
保留旧 ima/qa 工作树，不删除，不因此启动新会话或新子 Agent。

每个现有会话收到通知后，在下一安全检查点读入口、任务包、看板和通信协议；在信箱发给 coordinator 的回执包含：

```text
角色 / 当前工作树 / HEAD / 职责基线：
新职责理解：
当前任务继续 / 移交 / 暂停：
下一交付及验收条件：
依赖 / 阻塞 / 需要谁响应：
```

信箱不自动推送。职责通知由用户粘贴到现有会话；后续 Agent 按 `communication.md` 主动检查并直接交流。
