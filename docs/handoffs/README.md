# 角色交接

当前四角色各自维护 `coordinator.md`、`workflow.md`、`backend.md`、`frontend.md`，格式见 `../agent-start.md`。
旧 `ima.md`、`qa.md` 仅在原会话迁移时记录保留成果与停写交接；后续 IMA 成果统一由 Coordinator 报告。
基线前交接保留历史事实；旧 QA/独立 IMA 调度语句由 `../role-transition-v2.md` 替代，下一次交接使用新职责。
交接提交/合并是正式成果记录；短问答、阻塞、接口提案和回执走 `../communication.md` 的共享信箱。
