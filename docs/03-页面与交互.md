# 03 · 页面与交互需求

> **本文给"每页要满足什么"，不给"每页长什么样"。** 布局、组件、配色由实现者决定。
> 产品功能细节见 [02](02-产品功能与交互.md)；生成流程与提示词见 [04](04-智能体与提示词设计.md)。

## 1. 全局要求

### 1.1 导航
4 个入口有明确入口且点击可达：**营销图文（默认落地页）/ 客户跟进 / 销售培训 / 历史记录**。形式不限（侧栏、顶部标签、卡片首页都行），评委 10 秒内要能找到三个业务模块。

### 1.2 知识库状态位（始终可见）
```
● 已连接 · 任德耀新建华为PC知识库 · 最近一次检索：{上次生成时的时间}
```
- 始终显示"已连接"，不显示任何 key 片段
- 时间取**上一次实际生成时**的 ima 取图时间，悬停显示上次的产品名
- 这就是赛题"保留来源记录"的可视化

### 1.3 每个数据页面必须有 4 个状态
加载中 / 空 / 成功 / 失败（带原因与重试）。

### 1.4 编辑贯穿全局
凡是"生成出来的文字"都可编辑再保存：四段结果、客户卡解析结果、话术内容。

## 3. P1 营销图文工作台

### 3.1 必须承载
1. **产品区**：卡片含真实产品图 + 完整型号；相近型号必须是不同的卡
2. **人群区**：2-3 张卡，含人群名/典型任务/痛点/触发点/顾虑；可跳过
3. **平台区**：4 张卡，每张带**「目的」小切换**（默认到店体验，朋友圈与海报置灰）；卡上写明产出几张图
4. **风格卡片**（可选）：短语小卡，可多选、可自定义一个短语
5. **其他要求**（可选）：文本框 +「帮我问」

### 3.2 手动加卡
产品区和人群区都要有"添加"入口：**粘一段文字 → 解析成结构化字段（每项可编辑）→ 确认成卡**。

- 产品卡：价格字段标"待核验"并高亮；**生成时仍走 ima 检索**，查不到提示无法生成；与 ima 冲突以 ima 为准
- 人群卡：标"自定义"与"系统推荐"区分；空字段跳过，不要求填满

### 3.3 操作要求
- **产品必选**；人群与目的可选
- 产品与平台选好后即可生成
- 随时显示**当前组合回显**（产品 × 平台 × 目的 × 人群或"AI 判断"）
- 换产品后人群推荐自动刷新
- **只有卡片，没有搜索框和型号输入框**

### 3.4 必须处理的情况

| 情况 | 要求 |
|---|---|
| 加载中 | 骨架屏，不白屏 |
| 知识库不可用 | 明确提示 + 重试；**不展示假产品** |
| 该产品无资料 | 卡片标记不可选 |
| 生成失败 | 进结果页展示失败原因 + 重试 |

## 4. P2 生成过程 / 结果页

### 4.1 生成过程可见
按四段式顺序逐步点亮：`ima检索 → 一、场景判断 → 二、知识库依据 → 三、图文软文 → 三、配图 → 四、核验结果`

每步显示产物摘要（检索步要能看到资料标题、图片张数、取图时间），可展开看细节。**检索无结果时立即失败**，不进入后续。第一段若是 AI 推断，这一步就要显示「系统推断」。

### 4.2 四段结果
严格按赛题格式（见 [01 §1.3](01-赛题与产品定义.md)）：

1. **一、场景判断**：AI 推断处标「系统推断」+ **「换成我选的」回退键**（展开 2-3 候选，点选后重新生成）
2. **二、知识库依据**：每条事实带来源资料标题，可展开看 ima 原文摘录
3. **三、图文软文**：标题（含备选）/导语/正文/引导/标签 + 配图方案（缩略图、来源类型、说明、插入位置）
4. **四、核验结果**：逐项 通过 / 待确认 / 已拦截，说明删了什么

### 4.3 展示形态
- 长文型平台（公众号）能连续阅读
- 卡片型平台（小红书）能看出**每张图配哪段文字**
- 海报能预览最终画面

视图切换方式不限。

### 4.5 编辑图文
第三段整体可编辑：文字可改，配图可换/调序/删除。编辑时对风险表述**就地标黄**（价格、绝对化、伪造体验），不拦截。保存后核验重跑，原稿保留可对比。

### 4.6 底部折叠区「本次使用的提示词」（必须实现）
默认折叠，点开看到本次**实际拼装后**的完整 prompt：
- 原文照录，不美化不摘要
- 分调用展示（场景判断/事实挑选/写文/出图/核验），逐段可展开
- 标注模型名与耗时

这是"自研 Agent 与提示词 15 分"最直接的展示方式。

### 4.7 操作
底部：**复制全文 / 编辑图文 / 下载（文本+图片）/ 重新生成**。

**「重新生成」= 回 P1 从头来**，不提供就地换平台/换人群。每次结果都落库，可从历史记录重开。P2 与 P6 指向同一份数据。
