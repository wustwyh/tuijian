## 1. 模块 A：营销图文

### 1.1 输入流程

**1 个必选 + 2 个可选 + 1 个按钮**：

```
① 选产品（必选，点卡片）      ← ima 检索的锚点
      ↓
② 选目标客户（可选；不选则 AI 自判）
      ↓
③ 选平台（必选）+ 卡内"目的"小切换（可选）
      ↓
④ 可选：风格卡片、其他要求
      ↓
    [ 一键生成 ]  →  四段结果页
```

**正常路径零文本输入**，所有文本框默认折叠为"更多设置（可选）"。

### 1.2 产品卡（必选）

- **卡片直选**：真实产品图 + 完整型号，无搜索框、无输入框、无对话
- 型号必须到版本级：`MateBook 14（鸿蒙版）` 与 `MateBook 14 酷睿 Ultra` 是两张不同的卡
- 卡片内容来自 ima 检索，不写死

**手动加卡**：粘一段现成文字（官网描述、客服介绍），解析成可编辑字段 → 确认成卡。

```
粘贴："华为 MateBook D 16 2024，16英寸，1.68kg，i5，主打学生宿舍与居家办公，4599元起"
  ↓ 解析（每项可改）
型号 MateBook D 16 2024 / 尺寸 16英寸 / 重量 1.68kg / 处理器 i5
定位 学生宿舍·居家办公 / ⚠价格 4599元（待核验）
  ↓ 确认 → 变成可选卡，走同一条生成流水线
```

**规则**：手动卡只是"选品入口"，**生成时仍必须回查 ima**；检索不到就提示"该型号无资料，无法生成"；字段与 ima 冲突以 ima 为准；价格一律待核验、不进正文。

### 1.3 人群卡（可选）

- 选完产品后**自动推荐** 2-3 张，每张含：人群名、典型任务、核心痛点、购买触发点、主要顾虑
- 来源于赛题的 8 类场景
- 卡上标注："系统推荐 · 基于产品事实的营销假设"

**手动加人群卡**：同样粘一段话（门店自己的客户画像笔记），解析成人群名、典型任务、痛点、触发点、顾虑、购买阶段、内容切入点 → 确认成卡。

### 1.4 平台卡（必选）+ 目的小切换

| 卡片 | 产出形态 | 目的可切换 |
|---|---|---|
| 小红书种草 | 3–6 图图文 | 到店体验 / 咨询了解 |
| 公众号推文 | 2–4 图长文 | 到店体验 / 咨询了解 |
| 朋友圈到店 | 1–3 图短文案 | 仅到店（置灰） |
| 门店海报 | 1 张主视觉 | 仅到店（置灰） |

- 目的是**卡片内的一个小切换**，不是单独一组卡，也不是二维网格
- 默认"到店体验"，不切换也能生成
- 三类卡片**不做交叉筛选**：任何产品都能做任何平台，人群也不按平台筛

### 1.5 不选人群/目的时

| 用户选了 | 系统行为 |
|---|---|
| 人群 + 目的 | 严格按所选 |
| 只选人群 | AI 判断该用哪个目的 |
| 只选目的 | AI 推断人群 |
| 都不选 | AI 检索后自判，并说明理由 |

**两条硬约束**：
1. AI 判断的结果必须在第一段标 **「系统推断」**，不能伪装成用户选定
2. 必须提供 **「换成我选的」回退键**：展开 2-3 个候选，点一下重新生成

### 1.6 卡片字段全部进入提示词

**产品卡和人群卡的每个字段，最终都是生成用的提示词**，不是摆设：

| 字段 | 在提示词里的作用 |
|---|---|
| 产品：型号 | 锁定检索对象，防混用相近型号 |
| 产品：定位/卖点 | 与 ima 事实对齐后作为卖点候选 |
| 人群：典型任务 | 决定**使用场景**怎么描写 |
| 人群：核心痛点 | 决定**核心矛盾**怎么写 |
| 人群：购买触发点 | 决定**开头钩子**从哪切入 |
| 人群：主要顾虑 | 决定要提前化解哪些异议 |
| 人群：购买阶段 | 决定内容的激进程度 |

**填得越具体，生成越贴合**；空字段不猜，以"未提供"跳过。

### 1.7 两个可选模块

**风格小卡片**：`ins 风` / `幽默吐槽` / `专业测评` / `温情故事` / `开门见山` / `学院派`，可多选，可自定义一个短语。**只改写法，不改事实**（边界见 [04 §12](04-智能体与提示词设计.md)）。

**其他要求**：文本框 +「帮我问」。点「帮我问」后 AI 一次问一个问题、给 3-5 个选项，最多 3 轮，答完整理成一段可编辑文字回填。

```
"最想让人产生什么感觉？" [想买][想了解][想进店][想转发]
"有没有想突出的点？"     [轻便][续航][屏幕][协同][随你]
→ 整理成："希望唤起购买欲，重点突出轻便；其余按平台规则处理。"
```

规则：最多 3 轮、可随时退出、不强制；最终一定是**可编辑文字**；这段是用户意图不是事实依据，若写了产品参数，核验会拦掉并提示。

### 1.8 当季话题与时令素材（联网）

**唯一使用联网的地方**，核心原则：**素材跟着人群走**。同为 9 月，学生关心开学倒计时，上班族关心返工差旅。

| 层级 | 内容 | 例子 |
|---|---|---|
| ① 人群专属时令 | 该身份的时间轴节点 | 学生：距开学 14 天 |
| ② 人群专属话题 | 围绕该人群的讨论方向 | 学生："宿舍空间小、要能塞背包" |
| ③ 通用兜底 | 当季大环境 | 仅当①②为空时，界面弱化 |

**不能做**：查产品参数/价格/优惠；进入产品事实描述；成段搬运；脱离人群搜"本月热点"。

**界面位置**：结果页第三段顶部单独一栏，每条带层级标签，可逐条"用上"或"忽略"，用上后核验标「外部信息」。提示词见 [04 §10](04-智能体与提示词设计.md)。

### 1.9 生成过程可见

按四段式顺序实时点亮：

```
① ima 检索       ✓ 命中 3 份资料 / 5 张产品图
② 一、场景判断    ✓ 人群：开学季新生（系统推断）
③ 二、知识库依据  ✓ 摘录 7 条事实，均带出处
④ 三、图文软文    ⟳ 正在写正文
⑤ 三、配图        ○ 待生成
⑥ 四、核验结果    ○ 待核验
```

### 1.10 结果页

严格按四段组织（格式见 [01 §1.3](01-赛题与产品定义.md)）。第一段若含 AI 推断，标「系统推断」+ 回退键；第二段事实可展开看 ima 原文。

**最底部折叠区「本次使用的提示词」**：看本次实际拼装的 prompt 原文，分调用展示，不做美化。

底部操作：**复制 / 编辑图文 / 下载（文本+图片）/ 重新生成**。

### 1.11 编辑图文

第三段整体可编辑：标题、导语、正文、引导、图注可改字；配图可换/调序/删除。

- 编辑时**就地提示风险**（价格、绝对化用语、伪造个人体验），标黄但不拦截
- 可保存为新版本，原稿保留
- 保存后**核验重新跑**

### 1.12 重新生成与历史留档

**不提供"就地换平台/换人群"按钮**，想要别的组合就**回 P1 重选再生成**。每次生成本就是完整流水线，从头来因果链最清楚，也少一套"局部重算"的复杂度。

每次结果完整落库：输入快照 + 四段全文 + 图片出处 + 本次 prompt，全部可在历史记录里重开重下载。

### 1.13 海报

走"产品图 + AI 背景"分层合成，详细流程见 [04 §8](04-智能体与提示词设计.md)。结果页拆两层标注：`产品图 · 来源 ima` + `背景版式 · AI 生成`。
