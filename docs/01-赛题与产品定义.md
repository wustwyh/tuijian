# 01 · 赛题要求、评分对标与产品定义

> 本文是唯一的"为什么这么设计"依据。赛题原文见 [00-赛题手册原文提取](00-赛题手册原文提取.txt)。
> 读法：§1-2 是赛题客观要求，§3 是产品怎么接，§4 是判断题，§5 是红线。

---

## 1. 赛题与硬性要求

**AI + 华为PC营销软文智能体。** 自研 Agent 负责场景理解、平台匹配、提示词设计、图文组织、事实核验与合规；ima 共享知识库（"任德耀新建华为PC知识库"）提供产品**事实与图片**的唯一来源。可以调公开大模型，不要求自研基座。

### 1.1 流程必须闭环
```
场景解析 → 平台策略 → ima检索 → 事实点提取 → 图文编排 → 事实与图片核验 → 合规检查
```
缺任意一环，或检索没有保留来源记录，即为流程不完整。

### 1.2 提示词的 8 个必备模块
赛题原文："提示词不得只有'生成一篇软文'等简单指令"。模块是：角色与任务、场景理解、平台规则、知识库约束、图片规则、生成要求、核验规则、合规规则。（原文见 [04 §2](04-智能体与提示词设计.md)）

### 1.3 四段式输出格式（赛题指定）
```
一、场景判断   用户问题 / 内容目标 / 平台 / 目标人群 / 使用场景
二、知识库依据 产品型号 / 事实点 / 资料标题
三、图文软文   标题 / 导语 / 正文 / 行动引导 / 图片名称+来源+插入位置+说明
四、核验结果   产品事实 / 图片型号 / 合规 / 待确认信息
```
**结果页就按这四段组织**，不做自由排版——评委一眼能对上评分表。

### 1.4 平台规则（图片数量是硬指标）

| 平台 | 图文要求 |
|---|---|
| 公众号 | **2-4 图**，说明来源与插入位置 |
| 小红书 | **3-6 图**；**不得伪造个人体验** |
| 门店朋友圈 | **1-3 图**，优先主图与场景图 |
| 门店海报 | **1 张主视觉**，不得拉伸或错配型号 |

数量按平台不同而不同，这本身就是"平台适配 15 分"的得分点。四平台都出 3 张图 → 判"只改了字数"。

### 1.5 合规红线（触发即单项归零）

- 图**不是来自 ima** 或**与型号不符** → 图片引用项 **0 分**
- **虚构价格、补贴、销量、奖项、用户评价** → 准确性合规性 **0 分**

这是归零级判罚，必须做成**代码硬拦截**，不能靠提示词求模型别乱写。

### 1.6 凭证安全
APIKey / ClientID 不得出现在源码、README、截图、视频、提交文件中。界面**只显示连接状态**，永不回显 key 片段。

## 2. 图片：赛题怎么判，我们怎么做

赛题原话：「图片必须来自 ima；核对产品型号；输出图片来源、说明和建议插入位置」，扣分条款是「图片并非来自 ima 或与型号不符，图片引用项计 0 分」。

技术含义：**每张产品图都要能回答"属于哪个型号、从哪个条目来、什么时候取的"**。


## 3. 推鉴：产品定义

给华为 PC 门店销售用的营销智能体。两个定位：
1. **对销售**：把查资料、写文案、配图、校对、背话术压到最少
2. **对公司**：一个销售干过去几个人的活

| 模块 | 内容 | 权重 |
|---|---|---|
| **A 营销图文** | 选产品 → 选人群 → 选平台 → 一键出四平台图文，图片来自 ima，生成后逐条核验 | 主战场，覆盖约 85 分 |
| **B 客户跟进** | 聊天记录/留资页进池 → 意愿评估 → 跟进建议 | 次要，加厚场景理解 |
| **C 销售培训** | 产品 + 画像 → 话术/异议应对，可自测 | 次要，加厚 Agent 与提示词 |

详细交互见 [03](03-页面与交互.md)，生成流程与提示词见 [04](04-智能体与提示词设计.md)。

### 3.1 评分对标

| 评分项 | 分值 | 
|---|---|
| 业务场景理解 | **20** | 
| 产品事实准确性 | **20** | 
| 图文生成与图片引用 | 15 | 
| 平台适配与软文质量 | 15 | 
| 自研Agent与提示词 | 15 | 
| 功能完成度与体验 | 10 | 
| 合规与安全 | 5 | 

### 3.2 评委的"统一测试任务"

| 测试 | 输入变化 | 检查点 |
|---|---|---|
| 基础生成 | 指定产品+人群+场景+平台 | 检索、图文完整性、事实 |
| 换场景 | 同产品换人群/场景 | 切入点、卖点顺序、图片方案 |
| 换平台 | 同任务换平台 | 结构、语气、图数、引导 |
| 干扰与修改 | 易混淆型号、不完整信息 | 追问、核验、拦截、重生成 |

这就是为什么产品选择必须是**精确型号卡片**（鸿蒙版 vs 酷睿 Ultra 是经典陷阱），而非搜索框。

### 3.3 提交物
GitHub（源码+README，无密钥）、魔搭应用页、作品说明书（≥3 组结果，覆盖≥2 场景≥2 平台，标明资料与图片来源）、**Demo 运行视频**（一镜到底，不得 PPT 或剪辑拼接）。

## 4. 关键取舍

| 判断 | 结论 | 理由 |
|---|---|---|
| 主轴 | A 为主，B/C 为辅 | A 覆盖约 85 分，B/C 增量成本很低 |
| 产品范围 | 只要 ima 能检索到的型号都能做，卡片只是入口 | 不把能力限死在几个型号 |
| 产品卡 | **必选** | 它是 ima 检索的锚点 |
| 人群/目的 | **可选**，不选则 AI 自判并标注「系统推断」+ 回退键 | 减少必填项又不失可控 |
| 登录 | 形式化 | 评分表无身份项 |
| 智能体数量 | 4 次 LLM 调用（场景判断/事实挑选/写文/核验）+ 出图 | 按四段式倒推，不做多余 Agent |
| 生成后调整 | 只能回 P1 从头生成，旧结果全部留档 | 每次都是完整流水线，因果链最清晰 |
| 合规检查 | 代码级拦截 | 虚构内容判罚是单项 0 分 |
| 内容吸引力 | 可选风格卡片，**只改写法不改事实** | 不靠温度或模板去补知识库没有的内容 |
| 联网 | 真做，只产出「当季话题与时令素材」，**素材跟着人群走** | 补 ima 给不了的当下感，与事实严格隔离 |
| 视觉 | 华为红主色 | 用户指定 |

### 4.1 初赛评委反馈与我们的响应

评委原话要点："**素材跟真实产品要对的上，不做虚假传播，内容要吸引人，操作要足够简单让门店销售员减少工作量**。"

"鼓励打破规则"指**手段与表现**可以放开，**不是**放宽事实与合规。

| 评委点名 | 我们的做法 |
|---|---|
| 多轮对话 AI 追问出选择题 | **采用但只放在「其他要求」**，产品/人群/平台仍是点卡片，不拉长主路径 |
| 温度 / 提示词 skill 扩写 | **不采用扩写**，会用模板补知识库没有的内容；改为可选风格卡片，只改写法 |
| 联网搜索 | **真做**，专职产出当季话题与时令素材，单独成栏标「外部信息」 |
| 自建图片生成 | **分层**：AI 只生成背景版式，产品图原样合成 |

### 4.2 事实边界（对外口径）

| 主题 | 说法 |
|---|---|
| 知识库深度 | 库内以产品发现卡为主，精确配置/价格/服务承诺以官网和销售版本为准 |
| 人群与购买阶段 | 基于产品事实形成的营销假设，不是市场调研结论 |
| 客户意愿分 | 意向评估，供参考，可人工修正 |
| 时令素材 | 来自联网检索，标注「外部信息」，不构成产品事实 |
| 手动加的卡 | 字段来自用户粘贴文本，生成前必须回查 ima，价格一律待核验 |

---

## 5. 一句话红线

> **产品图必须来自 ima 且型号对得上；产品事实（型号/参数/功能/价格）只能来自 ima；价格/补贴/销量/奖项/用户评价一个都不能编；凭证一个字都不能露。**

其余表达方式可以放开：可以让 AI 生成海报背景、可以用风格卡片改写法、可以联网找时令话题。
