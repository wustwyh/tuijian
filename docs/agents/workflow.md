# Workflow 任务包

## 目标与阅读

实现画像→策略→两平台内容→核验，自研 Agent 负责表达与判断，ima 仅提供事实和图片。
共同入口后追加阅读：`api-contract.md` §2 画像/策略/成稿/证据、§3 Agent 流程、§5；`mvp-demo-plan.md` §4、§5。
只读 `packages/workflow/**`、共享类型和最小脱敏线上证据示例，不读本地全量知识库。

## 独占范围与依赖

- 独占 `packages/workflow/**`、提示词与模块测试、`docs/handoffs/workflow.md`。
- 不查业务数据库、不实现 ima SDK、不写 HTTP 路由、不改共享字段。
- 输入：任务、当前已保存证据、已确认画像/策略和 LLM 调用适配器；输出契约规定的结构化报告。
- 运行凭证由后端适配器管理，模块不直接读取或传递凭证值。

## 子任务与首次交付

1. W1：2—3 个画像与证据关联、营销假设和待确认项；单个主矛盾的策略。
2. W2：小红书、公众号平台结构及配图引用，保留型号与事实来源。
3. W3：事实、图片、型号、平台、合规核验；返回原因与证据引用。

首次交付可调用的画像/策略函数和结构化示例，再接内容与核验。不因 UI 未完成而等待。

## 验收

事实和图片只取自传入证据；未检索到的价格/销量/补贴/评价等不得补写。
核验同时包含可确定的引用/型号/字段规则与必要语义检查，不能仅相信模型自评“通过”。
同平台换人群、同人群换平台分别验证；缺图时报告不足，不重复或伪造素材凑数量。
交接给出模块函数入口、结构化样例、提示词位置、已验证与未验证内容。
