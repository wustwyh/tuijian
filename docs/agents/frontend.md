# Frontend 任务包

## 目标与阅读

实现营销员可演示的四页应用与任务工作台，不持有服务端凭证。
共同入口后追加阅读：`api-contract.md` §1、§2、§3 所调用端点、§5；`mvp-demo-plan.md` §2、§3、§5。只读 `apps/web/**` 及必要共享类型。

## 独占范围与依赖

- 独占 `apps/web/**`、模块内测试、`docs/handoffs/frontend.md`。
- 不改后端、共享契约、根配置和锁文件。需要依赖或字段时向 Coordinator 报送。
- 输入：共享契约与 Backend API。输出：页面、API 适配层、可复现交互说明。

## 子任务与首次交付

1. F1：登录/退出、路由保护、任务列表、创建任务。
2. F2：任务工作台五标签、型号候选、画像选择与确认、证据展示。
3. F3：策略、两平台成稿、图片/核验展示、导出、虚构客户跟进。

首次交付 F1 与工作台交互骨架。可用测试夹具开发组件，但必须明显标识且不进入正式运行路径；接口未就绪或失败应显示真实状态。

## 验收

刷新后可从后端重新读取结果；五个结果区块可见；未知项不伪装成已通过；图片对应真实证据且可追溯。
同一任务切换平台或修改输入后，按契约显示失效结果、加载和失败状态。
交接提供页面入口、调用端点、运行命令与尚未接通项；不能把组件测试通过等同于真实闭环完成。
