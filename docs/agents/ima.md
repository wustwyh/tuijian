# IMA 任务包

## 目标与阅读

从线上共享库“任德耀新建华为PC知识库”取得真实产品事实、图片与来源，不生成业务软文。
共同入口后追加阅读：`api-contract.md` §1、§2 EvidenceItem、§3 ima 检索与证据、§4；`mvp-demo-plan.md` §4.4、§5 用例 C。
技能分发包不纳入 Git。所有 worktree 均从主目录绝对路径 `E:\codes\创业\10.18黑客松\ima-skills-1.1.10\ima-skill\SKILL.md` 读取技能入口，再读其 `knowledge-base/SKILL.md` 与实际需要的接口说明；不要扫描知识库或解压材料。

## 独占范围与依赖

- 独占 `packages/ima/**`、模块内测试/诊断脚本、`docs/handoffs/ima.md`。
- 不写数据库、HTTP 路由、业务文案、前端或公共类型。
- 输入：查询、是否需要图片、已确认型号。输出：规范化未入库证据，或明确候选/错误。
- Backend 分配业务证据 ID；模块接口的正式签名由 Coordinator 冻结。

## 子任务与首次交付

1. I1：线上检索、读取至少 1 份 Markdown 和 1 张产品图；提供可接入服务入口。
2. I2：型号候选、来源与图片元数据、检索词/时间/适用版本、空结果/鉴权/读取失败。

首次交付真实证据包和脱敏联调说明；不等待整个应用。明确图片是否需代理/刷新，避免前端最后发现无法展示。

## 验收

`media_id` 来自 API；没有本地路径冒充线上 URL；未知型号不混用；无结果返回明确错误。
凭证仅运行时服务端读取，不进入源码、日志、交接或客户端。验证只报告配置状态，不读取输出凭证值。
提交输入/输出示例与可运行验证命令、尚未解决的外部权限问题；可接入部分完成后及时释放槽位。
