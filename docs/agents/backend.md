# Backend 任务包

## 目标与阅读

实现真实身份、持久化、用户隔离、HTTP 编排与导出。
共同入口后追加阅读 `api-contract.md` 全部、`mvp-demo-plan.md` §2、§8；源码限 `apps/api/**` 和必要服务接口。

## 独占范围与依赖

- 独占 `apps/api/**`、模块内测试与迁移、`docs/handoffs/backend.md`。
- 不改前端、ima 实现、Workflow 提示词、共享类型和根依赖。
- Coordinator 定义契约；IMA 提供未入库证据；Workflow 提供结构化结果。
- Backend 分配持久化 ID，负责 HTTP 路由和模块接入，避免与 IMA/Workflow 共改编排文件。

## 子任务与首次交付

1. B1：并行验证 Auth/Database 可用性，登录/退出/当前身份、双账号隔离。
2. B2：任务/证据/画像/策略/成稿/核验保存重开；轻量客户与跟进。
3. B3：ima 与 Workflow 接入、旧结果失效、Markdown/JSON 导出。

首次交付真实登录与任务 CRUD、两个账号无法互访的验证结果。不得用假持久化冒充数据库；服务不可用时报送具体阻塞。

## 验收

读写和导出都服务端验证所有权；证据属于当前任务；跟进关联的客户和任务都属于当前用户。
每次生成读取当前证据；请求返回时检查输入仍匹配，防止旧请求覆盖新型号任务。
外部错误统一映射，日志不输出凭证；图片访问不泄露鉴权信息。
交接给出接口、存储验证、身份隔离验证、上游待接入点。
