# Backend：服务与状态负责人

## 目标与阅读

让营销能力通过可靠接口运行、保存并隔离。共同入口后读 API 契约全部、Demo 方案 §2/§8、验收清单中 Backend 部分；定向读取自己的源码与依赖服务签名。

## 独占范围与依赖

- 独占 `apps/api/**`、模块测试/迁移、`docs/handoffs/backend.md`。
- 不改前端、IMA 实现、Workflow 提示词、共享类型或根依赖。接口草案交 Coordinator 收口。
- Coordinator 的 IMA 模块返回未入库证据；本模块分配 ID、检查所有权并保存；Workflow 消费当前证据与确认结果。
- 拥有 HTTP 路由、业务执行状态、输入版本、失效结果的持久化和过时回写保护。Workflow 定义业务依赖与修订规则，本模块负责可靠执行，不另写营销生成逻辑。

## 任务与交付

1. B1：登录/退出/当前身份、真实持久化、双账号隔离；对接 Frontend 并提交鉴权/响应草案。已有本地实现继续接续，存储提供方由 Coordinator/用户收口，不宣称已接入未验证的云服务。
2. B2：任务、证据、画像、策略、成稿、核验、轻量客户与跟进的保存重开。
3. B3：接入 IMA 与 Workflow；确认接口、下游失效、输入/证据版本、过时请求防护、Markdown/JSON 导出与核验限制。
4. B4：真实 LLM 适配器。按 Workflow 的调用需求交付服务端模型调用、结构化结果返回、错误映射、超时与有界传输重试；凭证仅服务端使用。与 Workflow 确认签名后由 Coordinator 冻结；不把假适配器当真实接入。
5. B5：图片访问。基于 IMA 的访问/有效期说明提供所需代理或刷新接口，保留图片和证据映射，不能泄露上游鉴权信息。

下一交付：复用已有 B1，提交前端可接入的鉴权/响应样例与 B4 适配器契约草案；按已冻结接缝推进真实适配器，缺服务配置时明确报阻塞。
W4 修订和 W5 跟进建议由 Workflow 输出；Backend 提供安全的调用、保存和状态更新，不自行生成第二套建议。

## 自验与交接

读取、修改、导出均在服务端校验所有权；关联的客户、任务和证据属于同一用户及正确任务。
自测持久化重开、双账号越权、输入修改失效、旧请求回写、失败/重试、导出限制和图片访问；前后端联调与 Frontend 直接沟通，缺陷不等待 QA。
各生成请求读取当前证据；日志不含凭证。模块测试、真实 LLM、真实 IMA 和完整闭环分别报告验证状态。
交付接口、函数签名、样例、实际命令与结果、未完成项和信箱消息 ID。
