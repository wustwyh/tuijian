# 新 Agent 最小阅读路由

## 目的

新会话没有项目记忆。本文件负责把 Agent 路由到当前任务所需材料，而不是要求从头阅读仓库。目录结构、模块与分支在本方案中仍是规划，未创建的文件不得报告为已完成。

## 所有人必读

1. `AGENT_CONTEXT.md`，一次完整阅读：产品目标、线上 ima 事实边界、凭证后端保存、用户隔离、验收红线。
2. 本文件，一次完整阅读。
3. 自己的 `docs/agents/<role>.md`，一次完整阅读。
4. `docs/agent-status.md`：只读全局事实、当前批次和自己的状态行；接手他人任务时再读关联行与最近交接。

根目录 `AGENTS.md` 是自动发现入口。人工启动时直接复制本文件末尾的指令。

## 按需读取，而不是全量扫描

- 先读入口和当前任务直接依赖的文件；查具体符号时在自己的目录或指定接口目录定向搜索。
- 上游信息不足时，请提供契约章节、函数签名、最小样例或交接摘要；不要把上游整个模块重新读一遍。
- 不读 `华为PC知识库/`、`任德耀新建华为PC知识库/`、知识库压缩包、`__MACOSX/`、`.workbuddy/memory/`、其他角色全部文档或历史日志。
- 只有出现明确需求时才定向查比赛手册的对应页、某个素材或某条历史记录。
- 不读取 `.env` 的值、令牌、私钥。运行时后端读取凭证；检查只报告是否配置。
- 测试夹具仅用于测试/开发，不进入正式运行链路，不冒充线上 ima 结果。

## 交接格式

每个角色只维护自己的 `docs/handoffs/<role>.md`。没有变化时不生成重复流水账；接班读最近交接即可。

```text
角色 / 分支 / worktree：
本次任务 ID / 契约版本或提交：
已交付：文件、导出入口或接口、提交号。
已验证：真实执行的命令及结果；未执行的明确注明。
接入说明：输入输出、调用示例或对应契约章节。
未完成 / 阻塞：缺什么，由谁处理。
下一步：具体到一个可验收动作。
```

共享看板由 Coordinator 更新；其他角色报告自己的交接路径，避免多人编辑同一张表。

