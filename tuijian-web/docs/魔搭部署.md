# 魔搭 Docker 创空间部署

选择 Docker，服务端口固定 7860。项目使用 Node.js 24，启动命令为 `npm start`，监听 `0.0.0.0:7860`。

上传 `tuijian-web` 文件夹内的文件到创空间仓库根目录，确保根目录直接包含 Dockerfile、package.json、package-lock.json、vite.config.js、index.html，以及 src、server、public、knowledge 文件夹。

不要上传 node_modules、dist、data、.tmp、.env。data 是本地运行记录和用户数据，不是必需的启动文件；云端首次启动自动建库。

knowledge 已打包运行必需的规则、产品图片、话术、培训、营销素材、FAQ 和客户场景。未包含价格政策机密目录、待审核或历史归档目录。

在创空间的服务端环境变量/密钥配置中设置：

- `DEEPSEEK_API_KEY`：自己的模型访问密钥。
- `DEEPSEEK_MODEL`：与本地实际使用的模型名称保持一致；未配置则使用代码默认值。

默认连接 DeepSeek 官方服务。若使用其他兼容服务，请在应用的用户设置中填写 API 地址、模型名称与密钥。

`KNOWLEDGE_ROOT` 已在 Dockerfile 设置为 `/app/knowledge`。不要上传包含密钥的 .env。

构建完成后，检查产品、客户、素材、图片加载，并执行一次真实生成与图文ZIP下载。云端默认不携带本地历史记录；未配置持久存储时，云端运行中新增的数据在实例重建后可能丢失。
